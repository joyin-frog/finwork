# UI 约定：间距节奏 · 交互态 · 界面文案

> 2026-07-18。与 `app/styles/tokens.css`（颜色主题）、`app/globals.css`（布局与风格）、`docs/spec/spec-typography-spacing-system.md`（字阶与间距阶的推导）配套。
> 本文只写"日常写界面时按什么规矩"，不重复 token 定义。

颜色主题与界面风格是两条独立轴：light / dark 只在 `app/styles/tokens.css` 定义语义颜色；default / linear 的 `data-style` 只负责布局、密度、圆角和层级策略。风格选择器可以使用 `var(--background)` 等语义色，不得定义或覆写颜色 token。

同一语义区域在不同界面风格中必须消费同一个颜色 token。现代风格把侧栏、Windows 标题栏和主内容四周露出的窗口底层视为一个连续外壳，全部使用 `--sidebar`；经典风格的侧栏同样使用 `--sidebar`，但窗口底层仍是页面 `--background`。两种风格只通过外边距、圆角、描边和阴影表达“平铺”与“浮起”，不再维护独立的窗口背板颜色。

现代风格不使用应用级顶部标签栏。全局搜索与侧栏收起按钮位于侧栏顶部；侧栏收起后，由各页面头部的展开按钮恢复导航。页面内部仍可按内容语义使用页签，例如智能体的工作、记忆、相关对话和概况。

平台窗口系统几何独立于界面风格。Windows 使用横贯全窗的 40px 自绘品牌标题栏：左侧为正式 Logo 与产品名 `Finwork`，右侧为最小化、最大化/还原、关闭；标题栏高度只走 `--window-chrome-height`，经典/现代共用。侧栏与主内容从标题栏下方开始，侧栏内部顶栏保持正常 `h-11`（44px），不得再为了窗口控件拉到窗口上缘或同步标题栏高度。macOS 继续使用系统红绿灯，不渲染品牌标题栏，侧栏几何不变。

## 一、间距节奏

单位永远走 Tailwind 4px 刻度（gap-1/2/3/4/5/6/8），不写任意值间距。三步节奏：

- **组内 8px**（`gap-2`）：同一控件组里的元素——图标与文字、一排按钮之间。
- **组间 16px**（`gap-4`）：一个区块内的相邻小组——表单项之间、卡片里的段落之间。
- **区块间 24–32px**（`gap-6` / `gap-8`）：页面级 section 之间。

卡片内边距：常规 `p-4`（16px），信息密的列表行/紧凑卡 `p-3`（12px），页面头部或强调区 `p-6`（24px）。同一视图内不混用两种以上卡片 padding。

**页签内容画布**：页面头部与页签是导航框架，不套卡片；每个页签承载的主要内容必须放进一个稳定的语义画布。智能体工作台统一复用 `AgentTabSurface`，工作、记忆、相关对话、概况以及各自的加载、空、错误状态都不能绕过它。画布是否存在属于信息结构，不由界面风格决定；default / linear 只通过 token 改变圆角、阴影、边框和密度。画布内可以为重复数据项使用次级行卡片，但不要再给整块内容套一层同级卡片。

**设置列表**：`SettingsSection` 为每个直接子项提供 `px-4`；子项之间的分隔线**首尾留缝**（`mx-4` + `h-px bg-border/50`），不贯穿卡片左右边缘。多项应作为 `SettingsSection` 的直接子项，由组件统一画线；不要再用 `-mx-4` 把内嵌列表拉满宽再画通栏线。`SettingsRow` 的右侧控件相对左侧整块（标题，或标题+`hint` 说明）**垂直居中**（`items-center`），不要用 `pt-*` 去「对齐标题第一行」。

**分隔线二分法**：

- **卡内行分隔**（设置分组内多项之间）：留缝发丝，`bg-border/50`。设置页与智能体「概况」卡共用此式；不默认扩散到聊天结果卡、驾驶舱等列表。
- **壳层结构线**（页头/底栏、列表与预览切开、表头与表体、对话框动作区）：继续通栏 `border-border`（或不透明描边），不要留缝、也不要减到 `/50` 以免结构发虚。

### 密集侧栏：紧凑行、宽分组

侧栏以“紧凑行、宽分组”为基本节奏：同组内容保持密集，把呼吸留给大分组。一级导航行高 36px，行与行连续排列（`gap-0`），不在点击高度之外再叠加空白；目录标题和二级条目为 32px，**同组二级条目也用 `gap-0`**（与一级同密）；分组标题与其下第一条之间仍用组容器 `gap-1`（4px）略作绑定。密集侧栏的大分组使用 `gap-5`（20px）。20px 是侧栏专用的宏观间距，不外推为页面区块间距；页面级 section 仍使用 24–32px。

侧栏遵守**双轴对齐**：不同尺寸的图形可以使用不同的图形—文字间距，但所有图形落在同一图形轴、所有标题落在同一文字轴。一级导航、岗位目录与会话行统一为 **`pl-2`（8px）+ 20px 图形槽 + `gap-2`（8px）**：图标距行左缘 = 图标距标题，图形列总宽 28px，标题自然对齐。分组标题（智能体/置顶/最近）落在图形轴；会话标题落在文字轴（与「新对话」齐），状态点与专员标记落在图形槽内。不要为了追求同一个 `gap`、或另写 `pl-4` 之类缩进破坏文字列。

侧栏选中/悬停框相对面板左右缝均为 **12px**：一级导航用外层 `px-3`；滚动列表用 `pl-3` + `scrollbar-gutter: stable`（右槽固定 12px，与全局滚动槽同宽），有无滚动条时选中框宽度都不跳。全局滚动槽 12px、可见 thumb 约 8px（2px 透明边）。

图标优先使用项目统一的 Hugeicons 线性图标。侧栏一级导航、智能体岗位与顶栏控件、设置齿轮默认 **16px**；更小的元信息用 12px（如折叠箭头）。侧栏智能体岗位用中性线性图标（`roleNavIcon`），不上岗位 tone 色底/圆形字标；智能体工作台页头只保留文字标题。彩色只承担状态（在忙/待拍板点）或其它场景的角色身份标记，选中态仍以低对比语义底色表达，不叠加描边和阴影。**派活 / 派任务**入口统一用 `ComputerUserIcon`（中性 ghost/outline，不用 primary 蓝底）。

短而稳定的核心目录默认采用**常驻目录**（分组始终出现在侧栏，不因空列表消失）。智能体、置顶、最近均可折叠：展开箭头贴在分组标题旁，默认隐藏，hover / 键盘焦点时再显示。智能体默认展开；会话区默认策略：有置顶时「最近」默认收起，无置顶时「最近」默认展开；只在置顶有无变化时套用，不覆盖用户手动开合。分组标题使用弱化字阶和较小的下间距，把标题视觉上绑定到它所说明的内容。

一级导航（新对话/总览/知识库/技能）固定；其下智能体、置顶、最近共用**一条滚动条**。滚动区上下边缘在有溢出且未贴边时用 **mask 渐隐淡出**（与总览 `.content-fade-top` 同思路，不用 blur），避免内容硬切。

## 二、交互态

- **hover 底色的正字**是 `hover:bg-accent`；列表行等大面积次级 hover 用 `hover:bg-muted`。两者语义：accent = 可点条目的悬停示意，muted = 弱一档的区域感应。
- 不用 Tailwind 调色板色（`blue-50`、`gray-100` 等）做任何交互态——它们不随主题与风格切换，一律走语义 token 或 tone token。
- 按下反馈全站统一是 `active:translate-y-px`（下沉 1px，见 button.tsx base），不另发明 `active:bg-*`。
- disabled 统一 `disabled:opacity-50 disabled:pointer-events-none`。
- 焦点环由全局 `outline-ring/50` 提供，不手动去 outline。
- **页内视图切换**使用 shadcn `Tabs` 的 `line` 变体，例如智能体的「工作 / 记忆 / 相关对话 / 概况」；不要改成筛选 chip。
- **列表分类筛选**统一使用 `app/shared/filter-chip-group.tsx`，例如知识库与技能分类；选中态为浅色 `accent`，不要在业务页各自手写黑色胶囊或按钮组。
- `Tabs` 与 `FilterChipGroup` 不混用：前者切换内容面板，后者只改变当前列表的筛选结果。
- 网格卡片里的按钮和操作图标必须固定在卡片边角，不随正文长度移动。卡片使用 `flex h-full flex-col`，hover 操作区统一复用 `CardActionDock`；常驻底部操作行至少使用 `mt-auto`。
- 可调宽列统一复用 `VerticalResizeDivider`：直接让现有列边界整高可拖，不再额外绘制短拖拽手柄。

## 三、界面文案

- **按钮 = 动词 + 宾语**：「生成凭证」「删除对话」「导入单据」；禁止「确定」「OK」「是」。危险操作按钮直说动作：「删除 3 条记录」。
- **标签/表头**用名词短语；正文、辅助说明、toast 用完整句。
- **错误 = 发生了什么 + 下一步**：「导入失败：第 3 行缺少金额列。修正后重新上传。」不写「操作失败，请重试」这种无信息量的话。
- **toast 点名对象、不说"成功"**：「凭证已生成」「对话已删除」；不带句号/感叹号，不写「成功生成凭证！」。
- **空状态指向第一个动作**：「还没有对话。点击左上角新建。」不只写「暂无数据」。
- **进行中用「…中」**：「生成中…」「上传中…」（省略号用 … 字符）。
- **数字与金额**：阿拉伯数字 + 千分位；金额列右对齐并加 `tabular-nums`；日期 `YYYY-MM-DD`。
- 语气：不用「请」开头、不用「哦/呀/~」、界面文案不出现感叹号；准确优先于客气。
