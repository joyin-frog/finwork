# 应收账龄台账 Skill

**定位：只读查询与账龄呈现，催款草稿由人发送（红线：催款函不自动发送）。**

---

## 执行流程

### 第一步：调用 query_receivables 获取应收清单

```
query_receivables(includeSettled=false)
```

若返回空清单（totalCount=0），说明当前无应收记录。**空清单不是错误**，引导语：
> "当前知识库中暂无应收记录。请先上传合同文件，并在知识库页面确认关键信息（对手方、金额、约定回款日）后，应收清单即可自动跟踪。"

### 第二步：账龄分箱呈现

账龄 = 约定回款日距查询日的天数（`agingDays`，工具已计算）。

**账龄分箱边界（集中在此处，唯一字面量来源）：**

| 分箱 | 条件 |
|---|---|
| 未到期（含今日到期） | agingDays ≥ 0 |
| 逾期 1-30 天 | -30 ≤ agingDays ≤ -1 |
| 逾期 31-60 天 | -60 ≤ agingDays ≤ -31 |
| 逾期 61-90 天 | -90 ≤ agingDays ≤ -61 |
| 逾期 90 天以上 | agingDays ≤ -91 |

**账龄口径声明（必须在报告末尾显式声明）：** 账龄自约定回款日起算（合同 due_date 字段），不从开票日计。

呈现用表格，示例格式：

```
## 应收账龄汇总（截至 YYYY-MM-DD）

| 分箱 | 笔数 | 金额合计（元） |
|---|---|---|
| 未到期 | N | X.XX |
| 逾期 1-30 天 | N | X.XX |
| 逾期 31-60 天 | N | X.XX |
| 逾期 61-90 天 | N | X.XX |
| 逾期 90 天以上 | N | X.XX |
| **合计** | **N** | **X.XX** |
```

**金额合计规则（严格执行）：**
- 金额来自工具返回的 `amountCents`（分值），换算：元 = amountCents / 100
- 禁止心算或从外部估算——一律用工具返回的分值换算
- 金额未知（amountCents 为 null）的笔数单列："另有 N 笔合同金额未知，未计入合计"
- 若所有行金额均未知，合计栏显示"无法汇总"

### 第三步：逾期催款清单草稿

对 agingDays < 0 的逾期项，生成催款清单草稿（措辞克制，不发送）：

```
## 逾期催款清单草稿

| 对手方 | 金额（元） | 逾期天数 | 合同来源 |
|---|---|---|---|
| XX公司 | X,XXX.XX | N 天 | 合同XX.pdf |
| ...（金额未知时标注"金额待确认"） |
```

**催款草稿措辞约束：** 只出清单，不起草催款函正文，不发送任何通知。

### 第四步：末尾三条固定声明

每次输出必须在末尾包含：

1. **账龄口径**：账龄自约定回款日起算，不从开票日计。
2. **金额未知说明**：（若有）另有 N 笔合同金额未知，已列出明细但未计入合计。
3. **回款核销说明（分场景）**：

   **在主对话中**：
   > 若您已收到某笔款项，请告知我（对手方名称与合同来源），我会起草"合同状态改为已收"草稿，**您在知识库页面点击确认后**，应收清单才会更新。

   **在子代理模式下（往来专员子代理）**：
   > 如需核销某笔应收（标记已收款），请回到主对话操作，在主对话中告知对手方名称与合同来源，主对话有权限完成核销确认。

---

## 执行约束

- **催款函禁止自动发送**：只出草稿，由人工决策后发送。
- **金额合计来自工具分值换算**：不心算，不从上下文估算。
- **空清单引导上传合同**：不报错，引导用户完善合同知识库。
- **账龄口径显式声明**：每次输出都在末尾声明口径（约定回款日）。
- **核销措辞分场景**：主对话可起草草稿待人确认；子代理无写权限，指示回主对话操作。
