# 财务分析 Skill

适用流程：财务分析

目标：
- 清洗费用表、工资表或报销登记表。
- 汇总部门、类目、月份和员工维度数据。
- 输出分析摘要和新分析表。

执行要求：
- 口径不明确时先提示财务确认。
- 只输出分析结果，不覆盖原始表格。
